#  Word Guessing Game – Python Project

A simple and fun Word Guessing Game built using *Python*, designed as part of the course requirement for VITYARTHI project. 
The project focuses on applying basic programming concepts such as loops, functions, user input handling, randomization, and error handling.

## Project Overview

This project allows a user to guess a hidden word letter by letter.  
The game randomly selects a word from a predefined list and displays blank spaces for each letter.  
The user keeps guessing letters until they either find the whole word or run out of attempts.

The goal of the project is to show understanding of:
- Python fundamentals  
- Conditional statements  
- Loops  
- String operations  
- Random module  
- Clean logical workflow  

## Features

- Random word selection  
- Shows progress after every guess  
- Tracks correct and wrong attempts  
- Limits number of guesses  
- Displays win/lose message  
- Simple and clean text-based UI  
- Fully modular code with functions  

## Tech Stack

- *Python 3*  
- Built using only standard libraries  
- No external dependencies required

##  How to Run the Project

1. Install Python (if not installed)  
2. Download or clone the project folder  
3. Open terminal inside the folder  
4. Run the following command:
python word_guess.py


## How to Play

1. The system randomly picks a word  
2. You guess one letter at a time  
3. If correct → the letter is revealed  
4. If wrong → attempts decrease  
5. Game ends when you:
   - Guess the full word (WIN)  
   - Run out of attempts (LOSE)
