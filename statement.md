# Project Statement – Word Guessing Game

## Problem Statement
Many students who are new to programming want to practice logical thinking in a fun and simple way. Traditional exercises often feel boring, so a small interactive game can make learning easier.  
This Word Guessing Game helps users improve their vocabulary and logical guessing ability by trying to guess a hidden word within limited attempts.

## Scope of the Project
The project includes a simple console-based word guessing system where:
- A random word is selected from a predefined list.
- The user tries to guess letters one by one.
- The system shows correct letters in their right positions.
- The attempt count decreases on wrong guesses.
- The user either wins by guessing all letters or loses when attempts finish.

## Target Users
- Students who are learning Python  
- Beginners practicing loops, strings, and logic  
- Anyone who enjoys quick and simple games  

## High-Level Features
- Random word selection  
- Display of hidden word structure ( _ _ _ )  
- Tracks number of attempts  
- Shows correct and incorrect guesses  
- Win/Lose result display
